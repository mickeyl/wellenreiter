# Wellenreiter for macOS

Curated internet radio in your menu bar, with favorites, listening history,
iCloud sync and a widget. Requires macOS 26 or later; supports Apple Silicon
and Intel Macs.

## Install

Download the latest signed and notarized ZIP from
[Releases](https://github.com/mickeyl/wellenreiter/releases), unzip it and move
Wellenreiter.app to Applications. Launch it to find Wellenreiter in the menu bar.

Or install with Homebrew:

```sh
brew install --cask mickeyl/formulae/wellenreiter
```

This repository distributes official macOS binaries. It does not contain the
application source code. The direct download and App Store edition are the same
app; install only one edition at a time.
